# Investor Transactions Analysis Report

## 1. Dataset Overview

- Total Transactions: 32,778
- Unique Investors: 5,000
- Unique Mutual Fund Schemes: 40
- Analysis Period: January 1, 2024 – May 30, 2025

## 2. Data Quality Analysis

- Missing Values: 0
- Duplicate Rows: 0
- Duplicate Investor-Date-Scheme-Transaction Records: 0
- Non-positive Transaction Amounts: 0

The dataset passed the initial data quality checks.

## 3. Transaction Type Analysis

SIP transactions were the most common, with 19,716 transactions (approximately 60.1%), followed by Lumpsum with 8,095 transactions (24.7%) and Redemption with 4,967 transactions (15.1%).

Lumpsum transactions contributed the highest total transaction amount of approximately ₹205.98 crore, followed by Redemption at ₹124.45 crore and SIP at ₹21.72 crore.

## 4. Monthly Transaction Trend Analysis

Monthly transaction activity remained relatively stable from January 2024 to May 2025, generally ranging between 1,754 and 2,020 transactions.

January 2025 recorded the highest transaction count at 2,020, while February 2025 recorded the lowest at 1,754.

The highest monthly transaction value was recorded in August 2024 at approximately ₹22.78 crore.

SIP transactions consistently dominated monthly transaction counts, indicating that recurring investments represented the most frequent transaction activity in the dataset.

## 5. Conclusion

The investor transaction dataset demonstrates stable monthly activity, with SIPs accounting for the largest number of transactions and Lumpsum investments contributing the highest total transaction value.
